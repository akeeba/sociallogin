What's new?

This is a security hardening release. We recommend that everyone updates.

Security hardening. As part of our commitment to security, this release addresses issues which could potentially have security repercussions under specific circumstances even though we cannot find a practical way to exploit them. Most of these have to do with the Login with Apple improvements described below, stricter rules about who can unlink social logins from other users' accounts, and logging. You can consult the CHANGELOG for the full list of issues addressed.

Spotify integration removed. Spotify discontinued the API login program this plugin relied on, so the Login with Spotify plugin has been removed. If you had it installed, Joomla will uninstall it as part of this update. You will see the message “Uninstalling the plugin PLG_SOCIALLOGIN_SPOTIFY was successful” when installing the new version confirming that. Users who only logged in through Spotify will need another way to log in, e.g. the password reset feature.

"Remember me" is now optional. Social logins used to always create a persistent "remember me" login. You can now turn this off in the System - Social Login plugin options.

Login with Apple improvements. The bundled phpseclib library was updated to version 3, and the signed login response is validated more strictly.
