What's new?

Login with Microsoft: Support for Azure Tenant ID. You can now use Login With Microsoft with applications scoped to a specific Azure tenant (for organisation or school accounts).

Preliminary support for Joomla 6. This version comes with preliminary compatibility with Joomla! 6. At the time of this writing, Joomla 6.0.0 Beta 1 has been released. That's our compatibility target. We expect more changes to take place before Joomla! 6 stable is released, with an as yet unknown impact on compatibility. We will keep following Joomla 6 development and adapting our software as necessary.

Bug fixes and minor improvements.
